# 真实数据案例：UCI Online Retail

来源：[UCI Online Retail](https://archive.ics.uci.edu/dataset/352/online-retail)。Chen, D. (2015)，[DOI](https://doi.org/10.24432/C5BW33)，[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。本项目对原数据做分类、聚合和敏感性分析，未改写原工作簿。

## 结论与口径

读取 541,909 行发票明细，时间覆盖 2010-12-01T08:26:00 至 2011-12-09T12:50:00。原始读取账本与 SQL 聚合金额及分类行数核对通过。

客户 ID 缺失 135,080 行，描述缺失 1,454 行。来源页面的元数据标记无缺失，与工作簿检查不一致；本报告以原文件的逐行验证为依据，保留这一来源矛盾。

正向销售行金额为 **£10,666,684.54**。若直接删除客户 ID 缺失行，会遗漏 **£1,755,276.64** 的正向销售金额。货币计算保留百万分之一英镑整数精度，展示时才舍入。

发现 5,268 行八字段相同的候选记录，但没有事件主键证明它们是错误重复。基线保留这些记录；若剔除候选重复，正向销售金额变为 £10,642,110.80，差额为 £24,573.74。

取消单单独作为负向记录流展示。未将取消单匹配到原始订单，因此不能把行数比例称为退款率。发票数据没有访问分母，也不能回答支付转化率或改版的因果影响。

## 建议与后续验证

1. 财务金额与客户行为使用不同纳入条件：未知客户仍计入金额，但不进入可识别客户队列。
2. 获取源系统行 ID 后再决定是否去重，先报告敏感性差异。
3. 对取消单补充原单关联和成熟窗口，再评估真实退款指标。
4. 对完整月份进行销售变化分解；先核对覆盖完整性，再讨论经营原因。
5. 本案例是历史公开数据分析，未声称改善真实业务指标。
